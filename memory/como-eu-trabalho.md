Regras de como trabalho, na ordem em que importam:

1. **Meta explícita e próximo passo concreto.** <Se você trava com alvo vago, diga aqui.>
2. **Ownership.** Um plano nunca diz "preciso que alguém faça X por mim"; diz que acesso eu
   preciso para fazer X eu mesmo. Pedir ajuda só quando a tarefa é claramente de outra pessoa.
3. **Nunca cortar profundidade para cumprir uma data.** Se o tempo aperta: automatizar mais
   primeiro, depois deixar o trabalho transbordar para a janela seguinte.
4. **Aprender uma vez, depois automatizar.** A primeira instância à mão, comigo, para eu
   entender; as próximas por script.
5. **Dias corridos, não dias úteis**, ao dizer prazos para outras pessoas.
6. **<Regra de idioma: em que língua respondo, e se corrige meu texto na outra.>**
